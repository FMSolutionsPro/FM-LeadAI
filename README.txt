FM LeadAI — FMSolutionsPro

This is a static interactive demonstration of an intelligent lead qualification workflow.

FILES
- index.html
- styles.css
- script.js
- favicon.svg

DEPLOYMENT
Upload all files to a GitHub repository, then import the repository into Vercel.
Framework preset: Other
Root directory: ./
No build command is required.

IMPORTANT
This demo uses deterministic rule-based scoring. It does not send data to an external AI service.
A production client version can be connected to:
- OpenAI or another AI API
- Email notifications
- CRM systems
- Google Sheets
- n8n / Make / Zapier
- Calendars and appointment booking
